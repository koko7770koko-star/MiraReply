# ミラ返信アシスト

MiraiMind（ミライマインド）の Android 版のチャット画面に重ねて、**返信候補を3つ**表示するアプリです。

- キャラクターから新しいメッセージが届くと、内容を読み取って返信候補を3つ作ります（共感・質問・遊び心など、方向性を変えて作ります）。
- 候補をタップすると、その文章を入力欄に入れて送信します。
- 候補を**長押し**すると、送信せずに入力欄へ入れるだけ（自分で直してから送れます）。
- 「自動会話」をオンにすると、キャラの返事が届くたびに候補を作り、ランダムな待ち時間のあと自動で送ります。最大回数・待ち時間は設定できます。オン中は丸ボタンがオレンジの「自」になり、画面も消えません。
- AIは次から選べます。
  - **端末内AI**（Gemma）: 無料・オフライン。
  - **Claude / OpenAI / Gemini の API**: 返信がかなり自然になります。直近の会話だけが送られます。APIが失敗した時は端末内AIに切り替えることもできます。

## v1.1 の変更点

- API（Claude / OpenAI / Gemini）での生成を追加
- 返信の質: キャラ名の自動取得、自分の設定欄、過去の言い回しの繰り返し防止、話題転換のルール、JSON出力で候補を安定して取り出す
- 読み取り: キャラの文が書き終わるまで待ってから生成、中央の日付・システム表示を除外、重複除去、吹き出しのまとめ方を改善、無視する文字を設定可能
- 操作: 長押しで入力だけ、送信できたかの確認と再試行
- 自動会話: 待ち時間ランダム、候補ランダム選択、最大回数、エラー時の再試行、画面を消さない
- 署名を固定（次回からは上書きインストールできます）

## 必要なもの

| | |
|---|---|
| スマホ | Android 12 以上、RAM 8GB 以上推奨（arm64） |
| 空き容量 | 約3GB（モデル 2.6GB） |
| パソコン | Android Studio（無料）。Windows と Mac のどちらでも使えます |

## 0. パソコンなしでAPKを作る（GitHub Actions）

1. GitHub で新しいリポジトリを作ります（Private で大丈夫です）。
2. このフォルダの中身を全部アップロードします（`.github` フォルダも含めます）。
3. 「Actions」タブを開き、「Build APK」が緑のチェックになるまで5〜10分待ちます。
4. 完了した実行を開き、下の方の Artifacts にある **MiraReply-apk** をダウンロードします。zip を展開すると `app-debug.apk` が入っています。
5. スマホでその APK を開いてインストールします（「提供元不明のアプリ」を許可してください）。

## 1. ビルドしてスマホに入れる（Android Studio を使う場合）

1. [Android Studio](https://developer.android.com/studio) をインストールします。
2. このフォルダ（`MiraReply`）を「Open」で開きます。初回は必要なファイルが自動でダウンロードされるので、数分待ちます。
3. スマホで **開発者向けオプション → USBデバッグ** をオンにして、USBでパソコンにつなぎます。
   （開発者向けオプションは、設定 → デバイス情報 → ビルド番号を7回タップすると出てきます。）
4. Android Studio の上部でスマホを選び、▶（Run）を押します。スマホに「ミラ返信アシスト」が入ります。

> APK ファイルにしたい場合は、メニューの Build → Build App Bundle(s) / APK(s) → Build APK(s) を選びます。

## 2. アプリの初期設定

1. アプリを開いて **①「モデルをダウンロード」** を押します（約2.6GB。Wi-Fi 推奨）。「準備済み ✅」になるまで待ちます。
2. **②「ユーザー補助の設定を開く」** を押し、「ミラ返信アシスト」をオンにします。
   - 「制限付き設定」と出てオンにできないときは、「このアプリの情報を開く」→ 右上の︙ →「制限付き設定を許可」を押してから、もう一度オンにします。
3. **③** で返信の雰囲気を書いて「設定を保存」を押します。
   例: `タメ口で優しく。たまに冗談も。1〜2文。` / `自分は大学生の男。敬語は使わない。`

## 3. 使い方

1. MiraiMind でチャットを開くと、画面の右側に紫の丸い「返」ボタンが出ます（ドラッグで動かせます）。
2. キャラクターの返事が届くと、上に候補パネルが開きます。生成には数秒かかります。
3. 候補をタップすると送信されます。気に入らないときは「再生成」を押します。

## うまく動かないとき

MiraiMind の画面の内部構造は公開されていないため、このアプリは **吹き出しが右寄りなら自分、左寄りならキャラクター** という見た目の位置で判定しています。
アプリの画面デザインによっては、読み取りや送信がずれることがあります。

- **候補は出るが、送信されない／入力欄に入らない**
  - 「返」→「画面構造」を押します。
  - 設定画面の「保存した画面構造を共有」でテキストを見て、入力欄（`editable`）と送信ボタン（入力欄の右の `clickable`）の `id=...` を探します。
  - 見つけた ID を詳細設定に入力します。
- **自分とキャラの発言が逆になる、関係ない文字を拾う**
  - 同じ手順で、メッセージ一覧（`scrollable` の RecyclerView など）の ID を指定します。
- **モデルの読み込みに失敗する**
  - 設定の「GPUを使う」をオフにします。CPU で動くので遅くなりますが、多くの機種で動きます。
- **遅い・重い**
  - 「AIに読ませる直近のメッセージ数」を減らします。

画面構造のテキストを Claude に貼ってもらえれば、設定する ID を一緒に探せます。

## 注意

- 自動操作は MiraiMind の利用規約に反する可能性があり、アカウントが制限されるおそれがあります。自己責任で使ってください。
- 自動送信をオンにすると、キャラクターとの会話が延々と続きます。必要なときだけ使ってください。
- 会話内容が端末の外に送られることはありません。

## ファイル構成

```
app/src/main/java/com/example/mirareply/
  ReplyAccessibilityService.kt  画面の見張り・生成の起動・入力と送信
  ChatReader.kt                 画面からメッセージ・入力欄・送信ボタンを探す
  LlmReplyEngine.kt             端末内AI（LiteRT-LM + Gemma）で候補を3つ作る
  OverlayPanel.kt               画面に重ねる「返」ボタンと候補パネル
  MainActivity.kt               設定画面
  Prefs.kt                      設定値・モデル情報
```

AIへの指示文（プロンプト）は `LlmReplyEngine.kt` の `generateReplies` にあります。
